
# HR Analytics Dashboard — Employee Attrition Overview
**Tool:** Power BI | **Domain:** HR Analytics

## 📊 Dashboard Preview
![HR Dashboard](Screenshot.png)

## 🎯 Project Overview
Interactive Power BI dashboard analyzing attrition patterns 
for 1,470+ employees across departments, job roles, and demographics.

## 📌 Key Insights
- **43 employees** analyzed with **39 avg age** and **14.65% salary hike**
- **Average Monthly Income:** ₹6.54K | **Avg Working Years:** 7.3
- **69.77% Male** vs **30.23% Female** workforce distribution
- **Life Sciences** dominates education field with 23 employees
- Sales Representatives show highest count with ₹8,766 monthly income

## ⚙️ Features Built
- KPI Cards — Count, Avg Age, Salary Hike %, Monthly Income
- Donut Charts — Overtime & Gender distribution
- Line Chart — Employee ID vs Monthly Income by Job Role
- Bar Chart — Education Field breakdown
- Slicers — Department, Gender, HourlyRate, PerformanceRating, JobLevel, JobSatisfaction
- Data Table — Job Role × Gender × Monthly Income breakdown

## 🛠️ Skills Used
- Power BI Desktop
- DAX Measures
- Power Query (Data Cleaning)
- Data Modeling
- Interactive Slicers & Filters
